# Minha Evangeline — site romântico

Projeto multipágina em HTML, CSS e JavaScript, inspirado no universo de A Princesa e o Sapo, com paleta verde e branca.

## Abrir
1. Extraia a pasta do ZIP.
2. Abra `Minha_Evangeline_Novo` no VS Code.
3. Instale/ative a extensão Live Server, se necessário.
4. Clique com o botão direito em `index.html` e selecione **Open with Live Server**.

## Personalização
- Edite `js/config.js` e altere `relationshipDate` para a data real do relacionamento no formato `AAAA-MM-DD`.
- Troque os textos de cada página para adicionar lembranças reais.
- Coloque fotos pessoais na pasta `assets/images` e altere os caminhos das imagens no HTML.
- As imagens de Tiana e Naveen atuais são carregadas de endereços externos e precisam de internet. Se um endereço deixar de funcionar, substitua por uma imagem local que você tenha direito de usar.
- O mural usa `localStorage`: as mensagens ficam apenas no navegador e não sincronizam entre aparelhos. Para login, privacidade e sincronização reais, seria necessário um backend e banco de dados.

## Páginas
Início, retrospectiva, história, cartinhas, quiz, memórias, baú, contador e mural.
